# Lições Aprendidas

## Conceitos Aprendidos

- Modelo de Responsabilidade Compartilhada
- Segurança da Nuvem
- Segurança na Nuvem
- IAM
- Security Groups
- Proteção de Dados

## Responsabilidade da AWS

A AWS é responsável por proteger:

- Data Centers
- Hardware
- Rede
- Virtualização
- Infraestrutura Global

## Responsabilidade do Cliente

O cliente é responsável por proteger:

- Dados
- Usuários
- Permissões
- Sistemas Operacionais
- Aplicações
- Configurações de Rede

## Relação com os Modelos de Serviço

### IaaS

Maior responsabilidade do cliente.

Exemplo:

- Amazon EC2

### PaaS

Responsabilidade compartilhada.

Exemplos:

- Amazon RDS
- AWS Lambda

### SaaS

Maior responsabilidade da AWS.

Exemplos:

- AWS Shield
- AWS Trusted Advisor
- Amazon Chime

## Destaque da Aula

Ter recursos hospedados na AWS não significa que toda a segurança é responsabilidade da AWS. O cliente continua responsável pela proteção de seus dados, usuários e configurações.

## Aplicação Prática

Ao utilizar serviços AWS, é essencial compreender quais controles de segurança são administrados pela AWS e quais devem ser configurados pelo cliente.
