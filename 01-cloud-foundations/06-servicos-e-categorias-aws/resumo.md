# Serviços e Categorias da AWS

## Introdução

A AWS oferece uma ampla variedade de serviços em nuvem organizados em categorias que atendem diferentes necessidades de infraestrutura, desenvolvimento, armazenamento, segurança e gerenciamento.

## Armazenamento

### Amazon S3

Serviço de armazenamento de objetos escalável, seguro e altamente durável.

### Amazon EBS

Armazenamento em bloco utilizado principalmente por instâncias Amazon EC2.

### Amazon EFS

Sistema de arquivos elástico e gerenciado para aplicações em nuvem.

### Amazon S3 Glacier

Serviço de armazenamento de baixo custo para arquivamento de longo prazo.

---

## Computação

### Amazon EC2

Serviço que fornece máquinas virtuais sob demanda na nuvem AWS.

### EC2 Auto Scaling

Ajusta automaticamente a quantidade de instâncias de acordo com a demanda.

### AWS Elastic Beanstalk

Facilita a implantação e gerenciamento de aplicações.

### AWS Lambda

Permite executar códigos sem gerenciar servidores.

---

## Contêineres

### Amazon ECS

Serviço de orquestração de contêineres.

### Amazon ECR

Repositório para armazenamento de imagens de contêineres.

### Amazon EKS

Serviço gerenciado para execução de Kubernetes.

### AWS Fargate

Execução de contêineres sem necessidade de administrar servidores.

---

## Banco de Dados

### Amazon RDS

Serviço gerenciado para bancos de dados relacionais.

### Amazon Aurora

Banco de dados relacional de alto desempenho.

### Amazon DynamoDB

Banco de dados NoSQL totalmente gerenciado.

### Amazon Redshift

Serviço de Data Warehouse para análise de grandes volumes de dados.

---

## Redes

### Amazon VPC

Permite criar redes privadas dentro da AWS.

### Elastic Load Balancing

Distribui tráfego entre múltiplos recursos.

### Amazon CloudFront

Rede global de distribuição de conteúdo (CDN).

### Amazon Route 53

Serviço DNS gerenciado da AWS.

---

## Segurança

### AWS IAM

Controle de usuários, grupos e permissões.

### AWS Organizations

Gerenciamento centralizado de múltiplas contas AWS.

### Amazon Cognito

Autenticação e autorização para aplicações.

### AWS KMS

Gerenciamento de chaves criptográficas.

### AWS Shield

Proteção contra ataques DDoS.

---

## Custos

### AWS Cost Explorer

Visualização e análise de gastos.

### AWS Budgets

Definição de orçamentos e alertas financeiros.

### AWS Cost and Usage Report

Relatórios detalhados de consumo e custos.

---

## Gerenciamento e Governança

### AWS Management Console

Interface gráfica para administração da AWS.

### Amazon CloudWatch

Monitoramento de aplicações e recursos.

### AWS CloudTrail

Registro e auditoria de atividades.

### AWS Config

Inventário e monitoramento de configurações.

### AWS Trusted Advisor

Recomendações para otimização de custo, segurança e desempenho.

---

## Conclusão

Os serviços da AWS são organizados em categorias para facilitar a identificação das soluções mais adequadas para cada cenário, permitindo a construção de ambientes seguros, escaláveis e altamente disponíveis.
