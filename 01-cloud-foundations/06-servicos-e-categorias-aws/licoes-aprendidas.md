- Contêineres
- Banco de Dados
- Redes
- Segurança
- Custos
- Governança

### Computação

- Amazon EC2
- AWS Lambda

### Armazenamento

- Amazon EBS

### Redes

- Amazon VPC

### Banco de Dados

- Amazon RDS

### Segurança

- AWS IAM
- AWS KMS

## Destaque da Aula

A AWS organiza seus serviços por categorias, facilitando a identificação da solução adequada para cada cenário de negócio ou necessidade técnica.

## Aplicação Prática

O conhecimento dessas categorias permite selecionar corretamente os serviços necessários para construir arquiteturas seguras, escaláveis e com alta disponibilidade.
