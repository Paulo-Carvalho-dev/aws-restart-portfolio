# Definição de Preços da AWS

## Introdução

A AWS utiliza um modelo de pagamento sob demanda (Pay-As-You-Go), permitindo que clientes paguem apenas pelos recursos efetivamente consumidos.

## Modelo de Precificação

Diferente da infraestrutura tradicional, a AWS elimina a necessidade de grandes investimentos iniciais em servidores e data centers.

O cliente utiliza recursos conforme a necessidade e é cobrado apenas pelo consumo realizado.

## Três Fatores Fundamentais de Custo

### Computação

Custos relacionados à utilização de recursos computacionais, como:

- Instâncias Amazon EC2
- Processamento
- Tempo de execução

### Armazenamento

Custos relacionados ao armazenamento de dados em serviços como:

- Amazon S3
- Amazon EBS
- Amazon Glacier

### Transferência de Dados

Custos relacionados ao tráfego de dados entre serviços, regiões e internet.

## Benefícios do Modelo AWS

- Sem investimento inicial elevado
- Pagamento pelo uso real
- Escalabilidade conforme demanda
- Controle de custos
- Flexibilidade financeira

## Conclusão

O modelo de precificação da AWS permite que empresas utilizem recursos tecnológicos de forma eficiente, pagando apenas pelo que utilizam e ajustando custos conforme suas necessidades.
