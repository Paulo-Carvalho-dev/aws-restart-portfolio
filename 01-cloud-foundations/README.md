# Cloud Foundations

## Sobre o módulo

Este módulo apresenta os conceitos fundamentais da Computação em Nuvem e os principais serviços da AWS.

## Objetivos

- Compreender o conceito de Cloud Computing
- Identificar os benefícios da computação em nuvem
- Conhecer a infraestrutura global da AWS
- Entender os modelos de serviço e implantação
- Aprender o modelo de responsabilidade compartilhada
- Conhecer os serviços Amazon S3 e Amazon EC2
