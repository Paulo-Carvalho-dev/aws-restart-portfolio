# Lições Aprendidas

## Conceitos Aprendidos

- Data Centers AWS
- Regiões AWS
- Availability Zones
- Pontos de Presença
- Amazon CloudFront
- Amazon Route 53

## Destaques da Aula

### Regiões

Localizações geográficas onde a AWS disponibiliza serviços e infraestrutura.

### Availability Zones

Conjuntos independentes de Data Centers dentro de uma Região, projetados para alta disponibilidade.

### Pontos de Presença

Locais que aproximam conteúdo e serviços dos usuários finais através de serviços de borda.

## Conceitos Importantes para a Certificação

- Diferença entre Região e Availability Zone
- Replicação entre regiões
- Redução de latência
- Alta disponibilidade
- Tolerância a falhas
- Resiliência

## Aplicação Prática

Ao projetar soluções na AWS, é recomendado distribuir recursos em múltiplas Availability Zones para aumentar disponibilidade e reduzir riscos de indisponibilidade.
